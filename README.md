# Spolvero

纯 vibe coding 项目：靠和 AI 编码助手对话，确定性地生成吴冠中风格的水墨动画。

你不必会画画，也不必会 Python。把想要的画面告诉 AI 助手（如 WorkBuddy），它读仓库里的 AGENT.md，写脚本、调库渲染、改到你满意。

## 现状

- 出片最稳的做法：让 AI 助手直接写 Python 调库。
- 网页控制台还在开发中，暂不要用。
- 仓库已含核心库、示例和文档；不含实验脚本与部分影片工程包。

## 怎么用

让 AI 助手读根目录的 AGENT.md，它会帮你配环境、跑示例、按你的想法做片。

## 内置风格

彩色水墨、蚀刻梦境等几种水墨预设，可切换。

## 文档

- AGENT.md：给 AI 助手看的，环境配置和做片方法都在里面。
- SPEC.md：工程规范。
